# Jack Nost Wall: WebFront 

This project connects the Firebase bucket with a react web app, that allows users to upload pictures which can then be pulled by the Jack Nost Wall and displayed live. 


### To Build: 
1. Open the terminal 
2. `cd` into the project root 
3. Run `npm run build` 
4. The build will be compiled into the docs folder
5. Currently this is configured to run with GitHub pages and attached with `https://arakhne.net`
6. GitHub Pages reads from the docs folder and goes live on the above-mentioned web address.
